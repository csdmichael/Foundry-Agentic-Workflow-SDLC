# Architecture diagram images

Place the exported slide images from
[`Microsoft-AI-Stack-for-SDLC.pptx`](../Microsoft-AI-Stack-for-SDLC.pptx) here so
they render in the root [README](../../README.md):

| Expected filename | Slide |
| --- | --- |
| `software-factory-architecture.png` | "AI Foundry–Based Software Factory Architecture" |
| `agentic-sdlc-operating-model.png` | "Agentic SDLC: Human Accountability + Agent Execution" |

To export from PowerPoint: open the deck → select the slide → **File ▸ Export ▸
PNG** (or right-click the slide graphic ▸ **Save as Picture**). The README and
[architecture.md](../architecture.md) reference these paths.

Until the PNGs are added, the Mermaid diagrams in
[architecture.md](../architecture.md) and [dataflow.md](../dataflow.md) provide
an equivalent, GitHub-rendered view.
